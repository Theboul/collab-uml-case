Guía Rápida
  • Arrastra desde los 4 puertos de una clase para conectar.
  • Clic derecho en una relación para tipo y multiplicidades.
  • Selección rectangular arrastrando sobre el fondo vacío.
  • Mantén pulsada la barra espaciadora para desplazar (pan).
  • Ctrl + Clic para sumar o quitar selección.
  • Supr para eliminar seleccionados.
